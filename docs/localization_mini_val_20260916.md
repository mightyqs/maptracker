## 验证协议

- mini-val 共 81 帧、2 个场景；与当前 mini-train 的 8 个场景无交集。
  这不保证上游 MapTracker 预训练权重未见过相同场景。
- 每帧 5 个固定、不同的网格扰动，共 405 组。seed 为 `20260916`。
  平移范围 ±3.6 m、间隔 1.2 m，yaw 范围 ±4°、间隔 2°，共 245 个候选。
- 100/300/500 次 checkpoint 完全共用目标帧、扰动和错配供体。
- 正确配对使用本帧图像；错配使用另一验证场景的完整六相机观测。
  供体图像先按自身几何生成 BEV 描述子，再与接收帧地图匹配。
- 基线预测零位姿修正，即不修正初始位姿。
- model.eval()、no_grad()、FP32、无历史；缓存描述子用于重复扰动测试。
  每个 checkpoint 的首帧检查缓存路径与完整定位 head 输出 logits 一致。
- 报告相对于目标修正的误差，平移取 x/y 差的 L2 范数，yaw 差做角度环绕。
  以下默认使用 MAP（最高分候选）输出，不是概率均值。

iter_500 正确配对的平移 P95 为 1.2 m，yaw P95 为 2°。

概率均值位姿明显弱于 MAP：iter_500 正确配对时，平移误差 1.061 m，yaw

iter_500 正确/错配的熵派生 confidence 均值分别为 0.223/0.028，具有区分
信号，但尚未校准为成功概率。错配时强制执行 MAP 修正比不修正更差，后续
必须评估拒绝更新机制，不能直接从均值选择部署阈值。

## 结论与下一步

已验证：在当前特征级合成任务中，正确配对明显优于错配和零修正；改变图像
后 iter_500 的 MAP 预测只有 1.48% 保持不变，支持匹配确实依赖观测。
语义学习的改善也迁移到了这两个验证场景。

尚未验证：真实带噪全局位姿下的地图查询、连续扰动、复杂跨场景泛化，以及
在线建图联合训练。跨场景错配是较容易的负例，也不能彻底排除合成边界/
位置特征捷径；405 组并非 405 个独立场景。

建议按顺序：

1. 可视化 scene-0916 失败帧的 BEV 语义、地图及概率体，定位 x/yaw 错误来源。
2. 增加同场景、不同位置的困难错配；使用内区评分或有效区域对照，评估变换
   边界的影响，再将扰动移到地图裁剪/栅格化之前，加入非网格连续位姿误差。
3. 在上述真实裁剪协议下比较 MAP 与峰值邻域细化，并评估 confidence 的
   接受率、接受样本误差和错误更新率；不能仅靠提高 logit scale 判断改进。
4. 固定新的验证协议后，再决定是否解冻 BEV 并联合建图训练。

当前可保留 iter_500 作为后续实验起点，同时保留 iter_300 对照：500 的命中率
和 yaw 稍好，但平移均值没有优于 300，不应宣称全面提升。
